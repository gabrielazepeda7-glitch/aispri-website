# AISPRI — Preliminary Responsive Website

This is a preliminary static HTML/CSS/JavaScript version based on the supplied
desktop and cellphone PDF mockups.

## Files

- index.html — main continuous one-page website
- style.css — responsive styling
- script.js — smooth navigation and active menu highlighting
- assets/ — place future PNG images and the final SVG logo here

## Current functionality

- One continuous scrolling page
- Fixed top navigation
- Navigation links scroll to each section
- Desktop navigation is horizontal
- Smartphone navigation is vertically stacked
- Responsive layout for desktop, tablet, and smartphone
- Arial font throughout
- Active menu item changes based on the section in view
- Preliminary contact form interaction

## Uploading to GoDaddy

For a standard static hosting setup, upload:
- index.html
- style.css
- script.js
- the assets folder

Place them in the public_html directory (or the document root for the domain).

## Important next step

The contact form currently does not send email. It needs to be connected to
a server-side PHP handler or a form service.

The temporary image placeholders and text logo should be replaced when the
final PNG images and SVG logo are provided.
